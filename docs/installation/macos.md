# macOS installation

Install Node.js 22+ through an official package or Homebrew, clone the repository, then run `./install.sh`. The installer refuses occupied ports, never terminates an existing process, uses only user-owned runtime directories, and creates `~/.local/bin/openzero` without overwriting a regular file. Set `OPENZERO_ROUTER_PORT` or `OPENZERO_CONSOLE_PORT` before installation to select unused ports.

Install the maintenance schedules with `openzero automation install`, review the generated user LaunchAgents in `~/Library/LaunchAgents`, then load them with `launchctl`. Discovery runs daily at 04:10 and the benchmark runs Sunday at 04:40 local time. Both jobs use exclusive locks, so overlapping invocations exit safely. `openzero automation status` prints the configured files and schedules. The installed plists reference the version-independent Homebrew `opt` path for Node, so they keep working after a `node@24` upgrade.

The effective Router and Console ports are resolved in this order: the `OPENZERO_ROUTER_PORT`/`OPENZERO_CONSOLE_PORT` environment variables, then `port`/`console_port` in `~/.openzero/config/routing.json` (or `~/.zerospend/config/routing.json`), then the `20129`/`20131` defaults. `openzero status`, `openzero dashboard`, `openzero doctor`, `openzero components`, and the Console all follow that resolution, so an installation moved onto other ports does not need extra shell variables to report itself correctly.
